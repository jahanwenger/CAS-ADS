# CAS Applied Data Science (2026/2027) - University of Bern

This repository contains the coursework, exercises, projects, and notes for my Certificate of Advanced Studies (CAS) in Applied Data Science at the University of Bern. 

## Repository Structure

The repository is organized by module, following the official 2026/2027 course schedule:

*   **module-1-data-management/**
    *   Focus: Data acquisition, data sources, and designing data management models.
*   **module-2-statistical-inference/**
    *   Focus: Statistical concepts for describing and analyzing data.
*   **module-3-machine-learning/**
    *   Focus: Standard data analysis techniques and state-of-the-art machine learning with Python.
*   **module-4-ethics-best-practices/**
    *   Focus: Code management, resource usage, quality assurance, and data protection legislation.
*   **module-5-peer-consulting/**
    *   Focus: Peer consulting, group discussions, and selected readings in data science.
*   **module-6-deep-learning/**
    *   Focus: Advanced neural network applications and practical methodology.

## Environment & Setup

The majority of the coding exercises and projects are implemented in Python.
